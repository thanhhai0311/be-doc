Sổ tay Java

Java hiện đại từ JDK 21 đến JDK 27: ngôn ngữ, thư viện chuẩn, lập trình đồng thời với virtual threads, công cụ JVM, và các design pattern viết theo phong cách Java mới (record, sealed, lambda). Mỗi phần có ví dụ chạy được và ghi rõ phiên bản JDK.

Java, JDK và lộ trình phiên bản

Java là ngôn ngữ hướng đối tượng, kiểu tĩnh, biên dịch ra bytecode rồi chạy trên JVM (Java Virtual Machine). Nhờ JVM, cùng một file .class chạy được trên mọi hệ điều hành có JVM.

Java ra bản mới mỗi 6 tháng (tháng 3 và tháng 9). Cứ 2 năm có một bản LTS được hỗ trợ dài hạn. Tính đến 11/2026: JDK 27 (phát hành 15/09/2026) là bản mới nhất, không phải LTS; các bản LTS gần đây là 17, 21, 25; LTS tiếp theo dự kiến là JDK 29 (09/2027). Dự án production nên chạy LTS.

JVM hoạt động thế nào

  1. javac biên dịchApp.java → App.class chứa bytecode, độc lập nền tảng.
  2. Class loaderNạp class khi lần đầu được dùng (lazy), theo thứ tự bootstrap → platform → application.
  3. Bytecode verifierKiểm tra bytecode hợp lệ và an toàn trước khi chạy.
  4. Interpreter + JITBan đầu thông dịch; method "nóng" được JIT (C1 rồi C2) biên dịch thành mã máy tối ưu.
  5. Garbage collectorTự giải phóng object không còn tham chiếu. Mặc định G1.

Ghi nhớ

Java luôn truyền theo giá trị. Với object, giá trị được truyền là tham chiếu: method sửa được nội dung object, nhưng gán biến tham số sang object khác không ảnh hưởng bên gọi.

Lập trình hướng đối tượng

public abstract class Account {
    private final String id;               // đóng gói: field private, chỉ đọc qua method
    protected long balance;

    protected Account(String id) {
        this.id = Objects.requireNonNull(id);
    }

    public String id() { return id; }

    public abstract long fee();            // lớp con bắt buộc cài đặt

    public void withdraw(long amount) {
        if (amount + fee() > balance) throw new IllegalStateException("Không đủ số dư");
        balance -= amount + fee();
    }
}

public final class PremiumAccount extends Account {   // final: không cho kế thừa tiếp
    public PremiumAccount(String id) { super(id); }

    @Override
    public long fee() { return 0; }
}

Interface

public interface Notifier {
    void send(String to, String msg);                        // abstract

    default void sendAll(List to, String msg) {      // default method: có thân
        to.forEach(t -> send(t, msg));
    }

    static Notifier noop() { return (to, msg) -> { }; }      // static factory

    private String format(String m) { return "[fraud] " + m; } // private helper (JDK 9+)
}

Một class chỉ kế thừa một class nhưng implement nhiều interface. Ưu tiên composition (giữ object khác làm field) hơn kế thừa khi chỉ muốn tái sử dụng code.

equals và hashCode

Hai object bằng nhau theo equals bắt buộc có cùng hashCode, nếu không HashMap/HashSet hoạt động sai. Cách dễ nhất là dùng record, compiler tự sinh cả hai.

@Override public boolean equals(Object o) {
    return o instanceof Money m && amount.equals(m.amount) && currency.equals(m.currency);
}
@Override public int hashCode() { return Objects.hash(amount, currency); }

Records Java 16

Record là class bất biến chỉ để chứa dữ liệu. Compiler tự sinh constructor, accessor (name(), không phải getName()), equals, hashCode, toString. Field luôn private final.

public record Money(BigDecimal amount, String currency) {

    public Money {                                        // compact constructor: validate + chuẩn hóa
        Objects.requireNonNull(amount);
        if (amount.signum() < 0) throw new IllegalArgumentException("Số tiền âm");
        currency = currency.toUpperCase();
        amount = amount.setScale(2, RoundingMode.HALF_UP);
    }

    public static Money vnd(long v) { return new Money(BigDecimal.valueOf(v), "VND"); }

    public Money plus(Money other) {                      // "sửa" = tạo object mới
        if (!currency.equals(other.currency)) throw new IllegalArgumentException("Khác loại tiền");
        return new Money(amount.add(other.amount), currency);
    }
}

var a = Money.vnd(100_000);
a.amount();                       // accessor
a.equals(Money.vnd(100_000));     // true: so sánh theo giá trị
  • Record có thể implement interface, có method, static field, nested record; không kế thừa class khác và không có field instance ngoài các thành phần.
  • Thành phần là List thì vẫn có thể bị sửa từ bên ngoài: sao chép phòng thủ bằng List.copyOf(list) trong compact constructor.
  • Dùng record cho DTO, value object, key của Map, kết quả trả về nhiều giá trị.

Enums

Enum trong Java là class đầy đủ: có field, constructor, method, thậm chí mỗi hằng có hành vi riêng.

public enum Plan {

    Plan(int monthlyVisitors, int priceUsd) {
        this.monthlyVisitors = monthlyVisitors;
        this.priceUsd = priceUsd;

    public boolean allows(int visitors) { return visitors <= monthlyVisitors; }

Sealed classes Java 17

sealed giới hạn những class nào được kế thừa/implement. Compiler biết chính xác tập con, nên switch không cần default và sẽ báo lỗi biên dịch khi thêm loại mới mà quên xử lý.

public sealed interface PaymentEvent permits Charged, Refunded, Disputed {}

public record Charged(String orderId, Money amount) implements PaymentEvent {}
public record Refunded(String orderId, Money amount, String reason) implements PaymentEvent {}
public record Disputed(String orderId) implements PaymentEvent {}

// lớp con của sealed class phải là final, sealed, hoặc non-sealed
public sealed abstract class Shape permits Circle, Polygon {}
public final class Circle extends Shape {}
public non-sealed class Polygon extends Shape {}     // mở lại cho kế thừa tự do

Sealed + record là cách Java mô hình hóa "kiểu tổng" (sum type / tagged union), tương tự union type trong TypeScript.

Pattern matching Java 21

// 1. instanceof pattern (Java 16): kiểm tra + ép kiểu trong một bước
if (obj instanceof String s && !s.isBlank()) {
    IO.println(s.length());
}

// 2. switch trên kiểu, có guard "when" (Java 21)
String describe(Object o) {
    return switch (o) {
        case null -> "null";                              // switch có thể xử lý null
        case Integer i when i > 100 -> "số lớn " + i;
        case Integer i -> "số " + i;
        case String s -> "chuỗi dài " + s.length();
        case int[] arr -> "mảng " + arr.length;
        default -> "khác";
    };
}

// 3. record pattern: tách thành phần (Java 21), lồng nhau được
String handle(PaymentEvent e) {
    return switch (e) {                                   // không cần default: sealed đã đủ
        case Charged(var id, Money(var amt, var cur)) -> "Thu " + amt + " " + cur + " cho " + id;
        case Refunded(var id, var money, var reason) -> "Hoàn " + id + ": " + reason;
        case Disputed(var id) -> "Tranh chấp " + id;
    };
}

// 4. biến không tên _ (Java 22): bỏ qua phần không dùng
case Refunded(var id, _, _) -> "Hoàn " + id;
try { parse(x); } catch (NumberFormatException _) { return 0; }
map.forEach((_, v) -> total += v);

Generics

Generics cho phép viết code dùng chung cho nhiều kiểu mà vẫn được kiểm tra lúc biên dịch.

// class generic
public class Page {
    private final List items;
    private final long total;
    public Page(List items, long total) { this.items = List.copyOf(items); this.total = total; }
    public  Page map(Function fn) {   // method generic
        return new Page<>(items.stream().map(fn).toList(), total);
    }
}

// bounded type: T phải so sánh được
public static > T max(List list) {
    T best = list.getFirst();
    for (T x : list) if (x.compareTo(best) > 0) best = x;
    return best;
}
